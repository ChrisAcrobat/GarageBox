# 27. Keyboard instrument toggle in top bar and start screen

**Decision:** **Keyboard instrument toggle lives in the top bar (checkbox) and on the start screen (button)**; global settings panel not built as a separate panel.

**Why:** Design 7.2 "global part"; the top bar already held the language picker.

**Alternatives:** A global settings dialog.

**Where:** `index.html`, `main.js`.

Milestone: Milestone 3 – more instruments

Importance: 5 – Visible UI placement, easy to change.
