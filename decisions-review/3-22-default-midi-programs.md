# 22. Default MIDI programs

**Decision:** **Default MIDI programs: guitar = Electric Guitar (clean) 27, bass = Electric Bass (finger) 33, keys = Acoustic Grand Piano 0**.

**Why:** The Xplorer is an electric guitar; R4c.11 for keys.

**Alternatives:** Steel acoustic (25).

**Where:** `setup.js DEFAULT_PROGRAMS`.

Milestone: Milestone 3 – more instruments

Importance: 3 – Decides how MIDI sources sound out of the box (keys use it by default).
