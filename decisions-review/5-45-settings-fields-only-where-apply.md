# 45. Settings fields only where they apply

**Decision:** **Settings fields shown only where they apply; whammy (and bend range only while the whammy bends) only for controllers with a whammy bar; tilt smoothing and the tilt glide checkbox only for controllers with a tilt sensor (so not for a gamepad in guitar mode).** (Updated for experiment E: there is no tilt assignment field any more.)

**Why:** Less clutter for a non-musician.

**Alternatives:** Always show everything.

**Where:** `settings-panel.js`.

Milestone: Milestone 4 – highway, settings, whammy/tilt

Importance: 5 – Reduces clutter in the settings panel.
