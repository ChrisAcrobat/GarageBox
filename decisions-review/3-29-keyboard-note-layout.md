# 29. Keyboard note layout

**Decision:** **Keyboard layout: home row A-L = C4-D5, upper row W E T Y U O P = C#4 D#4 F#4 G#4 A#4 C#5 D#5, bottom Z-M = C3-B3. Shift+Alt cancel out**.

**Why:** R4c.4 literally.

**Alternatives:** Base C3/C5.

**Where:** `keys.js KEY_OFFSETS`.

Milestone: Milestone 3 – more instruments

Importance: 3 – How the computer keyboard plays; mostly follows R4c.4 literally.
