# Experiment badge removed

**Decision:** The "Experiment E" badge in the top bar (with its long English tooltip), which came with the port of the whammy-E experiment, is removed together with its CSS and the "experiment" comments.

**Why:** The experiment is now the real feature (R4.5.x, R4.11.x); the badge is not in the docs and its tooltip was untranslated.

**Alternatives:** Keep it until the owner has tried the build.

**Where:** `src/index.html`, `src/css/style.css`.

Milestone: Build 1 – guitar, tilt and whammy

Importance: 8 – cosmetic.
