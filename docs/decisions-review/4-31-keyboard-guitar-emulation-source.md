# 31. Keyboard guitar emulation uses pluck and keyboard key/scale

**Decision:** **Keyboard's guitar emulation (1-5, Backspace) always uses the plucked string and the keyboard's key/scale settings**.

**Why:** Simple; keeps the piano program for the letter keys.

**Alternatives:** Separate settings for both parts.

**Where:** `setup.js`.

Milestone: Milestone 3 – more instruments

Importance: 4 – Audible but only in the secondary keyboard guitar mode.
