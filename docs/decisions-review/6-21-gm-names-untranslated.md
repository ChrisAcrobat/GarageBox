# 21. GM program names untranslated in common.json

**Decision:** **GM program names in `lang/common.json` (`gm.0`…`gm.127`), taken from the tinysynth source**.

**Why:** They are standard technical names, same in every language.

**Alternatives:** Translate 128 names into Swedish.

**Where:** `lang/common.json`.

Milestone: Milestone 3 – more instruments

Importance: 6 – Visible in the sound picker, but a standard naming choice.
