# Keyboard drums (importance 5)

Decision (owner, 2026-10-23): the computer keyboard instrument can choose Piano (default) or Drums (R4c.12, R4c.13). In Drums mode the letter keys play the MIDI drum kit (home row main kit, row above cymbals, bottom row extras). A small drum kit on the numeric keypad is always available while the keyboard instrument is on, also in Piano mode (R4c.14, R4c.15). Laptops without a numpad use Drums mode.
Open for review: the default letter mapping was chosen by the docs writer.
