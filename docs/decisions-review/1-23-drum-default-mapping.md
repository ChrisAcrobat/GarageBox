# 23. Drum default mapping

**Decision:** **Drum default mapping** (A kick, B snare, X closed hi-hat, Y low tom, LB crash, RB ride, LT open hi-hat, RT high tom, D-pad hi-mid tom / floor tom / clap / cowbell; guitar frets kick/snare/hi-hat/tom/crash, strum ride/open hi-hat).

**Why:** R4b.1 + making all buttons useful.

**Alternatives:** Leave D-pad silent.

**Where:** `drums.js DEFAULT_DRUM_MAP`, design 4.3.

Milestone: Milestone 3 – more instruments

Importance: 1 – Drums are the default gamepad instrument, so this is what most gamepad players play.
